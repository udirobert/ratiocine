# Ration (`ratiocine`) — Neutron app

A **certified reasoning logbook**: an AI agent solves hard pattern-deduction
problems (IOL/Linguini format), the canister grades the answers in-canister
(exact match + chrF), and every entry is chain-key-signed under an
installation-isolated slot — so anyone can verify *"this agent solved problem X
and earned grade Y"* against the ICP root key.

This directory is the **canonical source**. It syncs into a local clone of
[infu/neutron](https://github.com/infu/neutron) for building/packaging.

## Layout

| Path | Purpose |
|---|---|
| `backend/main.mo` | Motoko backend module (compiled INTO the user's canister) |
| `backend/memory/ratiocine/v1.mo` | Stable-memory schema (v1) |
| `src/` | React tile frontend (bundled by esbuild) |
| `neutron.json` | Format-3 manifest: capabilities, endpoints, tiles, memory |
| `neutron.lock.json` | Memory-schema lock (regenerated by packaging; commit it) |

## Architecture

```
User's Neutron canister (this app)
├── https_outcalls → POST {url_prefix}{path} → solve engine
├── grade in-canister (EM + chrF vs. ground truth)
├── chain_key_signing → sign (problem, attempt, grade) assertion
└── ledger (stable memory) + certified-asset publication

Solve engine (external, GPU):
├── Primary: https://ratiocine.trustfall.xyz/api/solve
│            (Netlify proxy → Modal L4 endpoint, scales to zero)
└── Fallback: https://ungethe--ratiocine-solve.modal.run/
             (path "" — flip url_prefix + path in neutron.json if needed)
```

The canister is the **verifier, not the compute**: inference happens on a
hosted GPU; everything provable (parsing, grading, signing, storage) happens
inside the canister.

## Build & install (local PocketIC)

```bash
# from ratiocine repo root
./scripts/sync-ration-app.sh          # mirror this dir → neutron/apps/ratiocine/
cd neutron
npm --workspace neutron-ratiocine run package   # validate + build + .neutron archive
npm run provision -- ration-local.ndeploy.json serve     # terminal 1 (keep running)
npm run provision -- ration-local.ndeploy.json reinstall # terminal 2
npm run provision -- ration-local.ndeploy.json status    # prints canister URL
```

Open `http://<canister-id>.localhost:8000/`, install Ration from the launcher,
approve the capability disclosures (HTTPS outcall prefix + chain-key slot).

Headless probing (owner identity = developer_identity_seed 2):
see `probe_local.ts` patterns in the repo history — methods are exposed on the
combined actor as `app_ratiocine__<func>` (compiler-owned `__` namespacing;
zero-arg funcs take a single `null` dispatcher argument).

## Known caveats

- **PocketIC cannot do real outbound HTTPS** — outcall probes return
  `management_failure` locally. Outcalls work on mainnet; local demos of the
  solve path need a mock or a pre-canned response.
- **Netlify sync-function timeout** is 10s default / 26s max (set in the
  Netlify dashboard → Site settings → Functions). The proxy aborts cleanly at
  `SOLVE_TIMEOUT_MS` (default 25000). Cold GPU starts on Modal take minutes —
  warm the engine with one solve before live demos.
- **Memory schema changes** break the lock: delete `neutron.lock.json` if you
  edit `v1.mo` before release.
- Chain-key signing on local PocketIC: **works** (verified 2026-08-18:
  `sig_ok`, 32-byte digest, 64-byte ECDSA signature; pubkey 33-byte compressed).
