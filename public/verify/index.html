Ration · public verifier

Verify an attestation

Every reasoning entry in a Ration ledger is signed with a chain-key assertion (ECDSA secp256k1, domain-separated per installation). A certificate chain links each signature back to the ICP root key, so anyone can confirm: this canister attested that this answer earned this grade — without trusting Ration, the model, or any middleman.

Client-side secp256k1 verification ships with the certified-ledger publish flow. Meanwhile, attestations can be checked against the canister's certified data and the IC root key directly.
