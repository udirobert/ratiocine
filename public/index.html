Ration

Certified reasoning ledger

Solves pattern-deduction problems, grades each attempt against ground truth in-canister, and chain-key-signs the result — producing attestations verifiable against the ICP root key.

Deterministic grading

Each ledger entry carries an exact-match + chrF score computed entirely within the canister and a threshold signature no single subnet node ever holds.

User-sovereign

Installs into your own Neutron canister. Problems, ledger, and consent boundaries remain local — no account, no shared infrastructure.

Agent-native

Exposes solve, grade, and get_ledger as typed entrypoints callable by any agent in your OS.

Signal Path

Dispatch The canister dispatches the problem to the inference engine via a declared HTTPS outcall.
Parse The engine returns candidate answers; the canister parses them using the Linguini evaluation protocol.
Grade Grading executes in-canister: exact match and chrF against the supplied ground truth.
Sign The (problem, attempt, grade) tuple is chain-key-signed and appended to the stable ledger.
Certify The ledger is publishable as a certified asset — third-party verification is possible, and absence of an entry is provable.
